Pagina Messi Legacy

Nombre del proyecto : Messi Legacy

Descripción: Esta página se creó con intención de contener una breve pero completa descripción sobre la carrera del mejor jugador de la historia Lionel Andres Messi, así como el detalle de sus títulos, partidos, goles y asistencias detalladas en una tabla además de una sección de registro para usuarios que quieran registrarse y recibir actualizaciones sobre este museo virtual de leo messi.
